# Rohit Bokam - Professional Portfolio

Welcome to the repository for my professional portfolio website! This project is a modern, minimalist, black-and-white themed portfolio designed to showcase my skills, experience, projects, and certifications. 

You can view the live site here: *(Add your live site link here, e.g., https://rohitbokam.github.io/)*

## 🚀 Features

* **Minimalist Black & White UI:** A striking, high-contrast design that emphasizes content, typography, and clean layouts.
* **Interactive 3D Background:** A dynamic, mouse-responsive particle network built using [Three.js](https://threejs.org/).
* **Scroll-Driven Animations:** Smooth, cinematic reveal animations and scaling text powered by [GSAP (GreenSock)](https://greensock.com/gsap/) and ScrollTrigger.
* **Interactive Timeline:** A scroll-linked progress timeline mapping out professional experience.
* **Dynamic Modals:** Interactive certification cards that trigger a custom modal window to display credential details.
* **Fully Responsive Grid System:** Mobile-first fluid CSS Grid and Flexbox layouts ensuring perfect display on desktops, tablets, and phones.
* **Premium Micro-interactions:** Custom button hover sweeps, subtle card lifts, and custom-styled progress bars for test scores.

## 🛠️ Technology Stack

* **Structure:** Semantic HTML5
* **Styling:** Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid)
* **Logic:** Vanilla JavaScript (ES6+)
* **Animation & Graphics:**
  * **Three.js** (WebGL 3D background rendering)
  * **GSAP** (Core animations, easing)
  * **GSAP ScrollTrigger** (Scroll-linked events)
* **Typography:** Inter & Outfit (Google Fonts)
* **Icons/Favicon:** Custom SVG/PNG assets

## 💻 Local Setup

Since this is a static frontend site, running it locally is incredibly easy.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rohitbokam/portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd portfolio
   ```
3. **Run a local server:**
   * If you have VS Code, you can use the **Live Server** extension.
   * If you have Python installed, run:
     ```bash
     python -m http.server 8000
     ```
4. **Open in Browser:**
   Navigate to `http://localhost:8000`
