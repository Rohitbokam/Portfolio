# Rohit Bokam – Portfolio

Static site, no build step. Open `index.html` or host the folder (GitHub Pages, Netlify, Vercel).

- `index.html` content (the View resume button links to your Google Drive file)
- `css/style.css` styles (responsive block at the end)
- `js/script.js` animations; projects in array `P` (title, dates, metrics `m`, bullets `b`), certificates in array `C`
- `favicon.svg`, `favicon.png` site icon
